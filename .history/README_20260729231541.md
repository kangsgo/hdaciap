# HDACiAP

Related code for the paper: *HDACiAP: A Curated Database and Analytical Platform for
Histone Deacetylase Inhibitors*.

## Data Cleaning Pipeline

Scripts in `data_clean/` process raw molecular data into analysis-ready datasets.

| Step | Script | Description |
|------|--------|-------------|
| 1 | `step1_split.py` | Split `molecules.csv` by `target_a` column into per-target subdirectories |
| 2 | `step2_clean.py` | Clean and standardize molecular records |
| 3 | `step3_makeclassic.py` | Generate classical molecular descriptors |
| 4 | `step4_simpleclassic.py` | Simplify classical descriptor sets |
| 5 | `step5_makere.py` | Build substructure/reaction enumeration |
| 6 | `step6_makere_clean.py` | Clean reaction enumeration results |
| 6a | `step6_makere_n_clean.py` | Clean nitrogen-containing reaction enumeration |
| 6b | `step6_makere_n_dup.py` | Deduplicate nitrogen-containing reaction enumeration |
| 7 | `step7_makere_dup.py` | Deduplicate reaction enumeration results |
| 7a | `step7_makere_n_cycle.py` | Cycle check for nitrogen-containing compounds |
| 8 | `step8_makere_n_dup.py` | Final deduplication of nitrogen-containing results |
| 8a | `step8_statusre.py` | Status reporting for reaction enumeration |
| 9 | `step9_scaffold_split.py` | Scaffold-based train/test splitting |
| 11 | `step11_relative_pic50.py` | Compute relative pIC₅₀ values |
| 12 | `step12_reg_pic50.py` | Regression analysis of pIC₅₀ |
| 13 | `step13_makere_n_statusre.py` | Combined reaction enumeration and status reporting |
| 14 | `step14_scaffold_split.py` | Alternative scaffold splitting scheme |

### Usage

Activate the required Conda environment before running any step:

```bash
conda activate prolif
python data_clean/step1_split.py
```

Each script is self-contained and operates on files within the current working
directory. Refer to the docstring of each script for detailed usage instructions.
